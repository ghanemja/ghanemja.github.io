# About me slide

An intro for Janelle Ghanem, as a PowerPoint file: an About Me slide and a How I Work slide.

- `About-Janelle.pptx` has both slides. Open it in PowerPoint or Keynote. The Agent Whiteboard GIF plays in slideshow mode.
- The tagline, the How I Work paragraph and the four loop steps are editable text. The name, greeting, site link and handwritten labels are images so the lettering looks the same on any computer. Every picture can be moved, resized or swapped.
- Speaker notes are in the notes pane.
- `images/` holds the original images (Agent Whiteboard, the Vanishing Gallery planet, the Behavior Search map and QR Compass) if you want to swap or reuse them.
